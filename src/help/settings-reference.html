Settings Reference (Complete Dialog Guide)

Main Connection Dialog

The main dialog is accessed via Net Connect (Ctrl+F1) in Total Commander. It contains all connection and transfer settings.

Connection Section

  • Connect to:
    • For SSH/SFTP: Enter hostname (e.g., example.com) or IP address
    • For PHP Agent/Shell: Enter full URL (e.g., https://example.com/sftp.php)
    • Supports custom ports: host:2222 or https://host:8443/sftp.php
    • IPv6 support: [::1]:22
  • Session: The name this session is saved under. Typing a different name renames it when you press OK. Sessions themselves are created with F7 and removed with F8/Delete in the plugin panel.
  • User name: SSH username (for SSH modes); optional label in PHP modes (not used for PHP auth)
  • Password:
    • SSH password authentication
    • PHP Agent shared secret, sent with every request (use HTTPS)
    • Stored encrypted via Windows DPAPI when "Save password" is used

Authentication Section

  • Use SSH agent (Pageant):
    • Automatically tries keys loaded in Pageant
    • Non-intrusive: falls back to other methods if no suitable key
    • Shows detailed log of which keys were tried
  • Certificate: Optional. An OpenSSH certificate (*-cert.pub) signed for the private key, for servers that log users in by certificate. Leave it empty otherwise: the public half of the key is derived from the private key file. A private key entered here by mistake is still used to log in.
  • Private key file:
    • Accepts PEM format (OpenSSH)
    • Accepts PPK format (PuTTY) — native conversion, no external tool or DLL needed
    • Supports encrypted keys with passphrase prompt
    • PPK v2 and PPK v3 (Argon2) both supported natively — Argon2 is built into the plugin

Transfer Mode Section

  • Transfer mode dropdown:
    • SSH (SFTP/SCP) - Standard SSH file transfer
    • Use SCP for data transfers (checkbox) - SFTP for listing, SCP for transfers
    • Use SCP for everything (no SFTP) (checkbox) - Pure SCP mode
    • Use shell transfer (for blocked hosts) (checkbox) - Shell command pipeline
    • PHP Agent (HTTP) - HTTP-based file operations
    • PHP Shell (HTTP) - HTTP pseudo-terminal
    • LAN Pair - direct Windows-to-Windows pairing
  • TAR stream (checkbox, PHP Agent / PHP Shell modes only): when checked, directory downloads use a single TAR_STREAM GET request and batch uploads use a single TAR_EXTRACT POST instead of per-file requests. Greatly reduces round-trip overhead for many small files.
  • Method (PHP Agent / PHP Shell modes only): HTTP verb for single-file uploads — Auto (POST→PUT fallback), POST, or PUT.
  • Chunks (PHP Agent / PHP Shell modes only): upload chunk size — Auto (from server PROBE, 1–64 MiB), or fixed 2 / 4 / 8 / 16 / 32 / 64 MiB.
  • Compress data with ZLIB: Enable SSH compression (may help on slow links)
  • Use shell transfer (for blocked hosts):
    • Enables cat/dd/base64 pipeline fallback
    • Use when SCP/SFTP are blocked by server policy
    • Supports resume with base64 alignment (3-byte boundaries)

Jump Host

  • Use jump host: Enables ProxyJump / bastion routing for SSH mode
  • Jump... Opens dedicated Jump Host configuration dialog
  • Jump Host settings are only active for SSH (SFTP/SCP)
  • Jump Host is disabled for PHP Agent, PHP Shell, and LAN Pair modes

LAN Pair Controls

  • Role: Auto / Receiver / Donor — controls which side initiates the connection; see LAN Pair for details
  • Peer: Detected LAN peer dropdown
  • Session timeout: Minutes; 0 means no limit
  • Trusted Installer (checkbox): When checked, the local LAN Pair file server impersonates the TrustedInstaller account when serving incoming connections. This allows a remote peer to read and write files that are owned by TrustedInstaller (Windows system files, Windows Update directories, etc.) on this machine. Requires that the process has SeDebugPrivilege; Total Commander normally runs with sufficient privileges. See LAN Pair → TrustedInstaller for a full explanation.
  • Pair... Starts pairing or role negotiation

Plugin-wide settings (language override, etc.) are stored in the [Configuration] section of sftpplug.ini. See the dedicated page for the file location, all available keys, and examples including custom translation files:

→ Plugin Configuration (sftpplug.ini)

Advanced Options

  • Detailed log: Enable verbose logging; output appears in the TC log window (F5 log pane or separate log window)
  • Show entire directory listings in log: Includes full remote ls -la output in the log — useful for diagnosing SCP/shell listing problems

Permissions, Owner and Group

The plugin offers custom columns for remote files:

  • permissions — as ls writes them, e.g. rwxr-xr-x, with s/t for setuid, setgid and sticky
  • octal — the same as a number, e.g. 0755
  • owner and group — names; a server that sends no names shows the numeric ids
  • link target — where a symbolic link points

Total Commander picks up a default view for the plugin on its own: size, date, permissions, owner and group. Other combinations are set up under Configuration → Custom columns, file system Secure FTP. The values come from the directory listing in SFTP and SCP mode; PHP Agent and LAN Pair leave the columns empty.

Alt+Enter on a remote file opens its properties: path, link target, owner, group, permissions, size and date as the listing gave them, and below that the reply of stat run on the server. A server without a shell shows what the SFTP protocol reports instead. The window is for viewing only.

To change permissions, use Files → Change Attributes (Alt+A) on one or more remote files. Over SFTP the mode is set through the protocol, which also works on servers without a shell; in SCP mode the plugin runs chmod. Owner and group cannot be changed from the plugin.

Character Encoding

  • UTF-8 for filenames:
    • Auto-detect: Plugin tries to detect server encoding
    • Force UTF-8: Always use UTF-8 encoding
    • Force ANSI: Use system codepage
  • Text file types: Wildcard patterns for text mode transfers (e.g., *.txt;*.log;*.ini)
  • Transfer mode:
    • Binary: Raw byte transfer (default)
    • ASCII: Convert line endings (CRLF ? LF)
    • Auto: Use wildcard patterns to decide

Proxy Configuration Dialog

Accessed via Proxy... button. Configure network proxy for SSH connections.

Proxy Types

  • No proxy: Direct connection
  • HTTP CONNECT: HTTP proxy using CONNECT method
  • SOCKS4a: SOCKS version 4a (supports domain names)
  • SOCKS5: SOCKS version 5 (full authentication support)

Proxy Settings

  • Proxy server: Hostname or IP, optional port (proxy:1080)
  • Username: Proxy authentication username
  • Password: Proxy authentication password (stored encrypted)

Proxy Error Messages

  • Connection not allowed - Proxy policy blocks destination
  • Network unreachable - Target network not reachable via proxy
  • Host unreachable - Specific host not reachable
  • Connection refused - Target actively refused connection
  • TTL expired - Routing loop or timeout
  • Command not supported - Proxy doesn't support requested operation
  • Address type not supported - IPv6/hostname not supported by proxy

Keyboard Shortcuts (Connection Dialog)

  • F7 - Create new session (opens "New folder" dialog for naming)
  • F8 / Delete - Delete selected session
  • Enter - Connect with current settings
  • Alt+Enter - Edit selected session properties

Session Storage

  • Sessions stored in sftpplug.ini in Total Commander directory
  • Passwords encrypted with Windows DPAPI (user-specific)
  • Sessions from SecureCRT, PuTTY, WinSCP, FileZilla and KiTTY appear in the [Imports] folder in the plugin root
  • Cached session lists live next to sftpplug.ini, so imported entries are available right after Total Commander starts
  • Custom locations added through [Add custom location...] are stored per source in sftpplug.ini
Tip: After importing from WinSCP, verify transfer mode settings — SCP sessions arrive with scponly=1 and scpfordata=1. Proxy definitions are not imported from any source and have to be set up again. See Import sessions from other programs.
