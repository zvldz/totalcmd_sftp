PHP Shell Console

Console-style pseudo-terminal over HTTP for remote command execution through sftp.php.

Features

  • Prompt with host and working directory.
  • Command history (Up/Down).
  • Basic completion and list suggestions.
  • Colored output: prompt/command/output separation.

Turning the shell on in the agent

Shell commands are off in sftp.php by default, and the agent answers SHELL_DISABLED. To use the console, turn them on on the server, in one of two ways:

  • in sftp.php: const AGENT_ALLOW_SHELL = true;
  • or in the web server's environment: TC_SFTP_AGENT_ALLOW_SHELL=1 (for example SetEnv TC_SFTP_AGENT_ALLOW_SHELL 1 in Apache).

Commands run as the web server user and are not confined to the agent root: whoever holds the password gets that access. Turn the shell on only where you need it.

The command and the working directory are sent in the request body, not in the URL, so they do not appear in web server or proxy access logs. Use https://: over plain HTTP the password and the commands travel unencrypted.

Open behavior

The Shell... button validates PHP auth first. On auth errors, console does not open and an explicit error is shown.

Known limits

  • This is not a full PTY/TTY emulator.
  • Some terminal-native behaviors may differ from PuTTY/OpenSSH shell.
